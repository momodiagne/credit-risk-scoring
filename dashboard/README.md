# Interface Utilisateur (Dashboard Conseiller)

Ce dossier contient les fichiers de l'interface graphique de simulation destinée aux conseillers bancaires.

## Rôle principal

L'interface utilisateur permet au conseiller d'interagir simplement avec le système d'analyse :
1. **Formulaire latéral** : Permet d'entrer ou de modifier le profil financier d'un emprunteur.
2. **Boîte de décision** : Affiche clairement l'avis final (Crédit Accordé ou Refusé) ainsi que le niveau d'exposition au risque.
3. **Graphiques explicatifs** : Détaillent les facteurs qui favorisent le dossier et les éléments nécessitant de la vigilance.
4. **Tableau de synthèse** : Récapitule l'ensemble des critères financiers évalués.

## Fichiers du dossier

* `app.py` : Code de l'application web interactive.
* `style.css` : Feuille de style personnalisée pour l'habillage visuel de l'interface.
