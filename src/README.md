# Code Source (Pipeline de Traitement & Calculs)

Ce dossier regroupe l'ensemble des modules de traitement de données et d'entraînement du système d'évaluation.

## Organisation des sous-dossiers

* `data/` : Scripts de nettoyage et d'ajustement des données financières brutes.
* `features/` : Scripts de création d'indicateurs financiers synthétiques (score de retards cumulés, revenus par personne à charge).
* `models/` : Scripts de configuration, d'entraînement et d'évaluation des performances du système d'analyse.
